# Mesh Viewer

**Mesh Viewer** is a lightweight C++ OpenGL project that lets you load and display 3D models (starting with `.obj` files).  

Right now, it handles basic geometry, but the plan is to grow it into a small but capable tool with textures, PBR, and maybe even mesh editing features. The goal serves as a personal playground to implement different state-of-the-art and also experimental CG Rendering techniques.

## Implemented
- Blinn-Phong Shading
- Cubemap Skybox lighting
- Shadow Mapping
- SSAO


## Plans

This project is still early, but goal:

- Physically-Based Rendering (PBR)
- Material support
- Mesh transformations (move, scale, rotate)
- A user interface using ImGui for toggles and loading new models
